## Usage

1. Download and extract the repository files.
2. Open the `/docs` folder and read the `GettingStarted.md` guide.
3. Choose your desired configuration:
   - **Scripts:** Run the automation scripts from `/scripts` via CorelDRAW's built-in scripting or VBA.
   - **Templates:** Import the design and print templates from `/templates` via CorelDRAW's "File > Open" or "Import" function.
   - **Presets:** Apply the AI, brush, and color presets from `/presets`.
4. Launch CorelDRAW Graphics Suite and follow the documentation to apply your configurations.
